# Examples

Configuration examples and templates for Amazon RDS for DB2 implementations.

## Available Examples

- **[SSL Connection to RDS for DB2](ssl/)**: Using region PEM certificates
- **[RDP over AWS Systems Manager](rdp-script/)**: Connect from macOS to a Windows EC2 instance in a private subnet using a Session Manager port forwarding tunnel, with no public IP, inbound security group rule, bastion or VPN
